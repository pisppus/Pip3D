Pip3D is a lightweight, high-performance 3D graphics and physics engine with low overhead, designed specifically for microcontrollers (currently supporting only the ESP32-S3). It runs directly on top of the PipCore system kernel.

The engine integrates a flexible scene graph system with hierarchical transformations, perspective, orthographic, and fisheye camera projections, as well as automated keyframe animation. A realistic lighting pipeline supports directional and point light sources, silhouette lighting, and soft planar shadows. The Pip3D physics module includes a full-featured rigid-body dynamics simulator with sphere and box collisions, constraint solving, Verle integration-based rope simulation, and realistic buoyancy of bodies in water.
