Pip3D — это легковесный, высокопроизводительный движок трехмерной графики и физики с низкими накладными расходами, разработанный специально для микроконтроллеров (пока поддержка только ESP32-S3). Работая непосредственно поверх системного ядра PipCore.

Движок интегрирует гибкую систему графа сцены с иерархическими трансформациями, перспективную, ортографическую и фишай-проекции камеры, а также автоматизированную шкалу анимации по ключевым кадрам. Реалистичный конвейер освещения поддерживает направленные и точечные источники, силуэтную подсветку и мягкие планарные тени. Физический модуль Pip3D содержит полноценный симулятор динамики твердых тел со столкновением сфер и параллелепипедов, решением ограничений, симуляцией веревок на основе интеграции Верле и реалистичной плавучестью тел в воде.
